# سیستم میز خدمات (Help Desk)

سیستم میز خدماتی که برای مدیریت درخواست‌های پشتیبانی فناوری اطلاعات (IT) در محیط دانشگاهی طراحی شده است. 

علاوه بر قابلیت‌های اصلی مدیریت تیکت، از جمله پیگیری، تخصیص و ارتباطات، این سیستم ویژگی‌های مبتنی بر هوش مصنوعی مانند دسته‌بندی درخواست‌ها، پیش‌بینی اولویت و ارائه پیشنهادهای هوشمند پشتیبانی را نیز ارائه می‌دهد.

## نحوه اجرا

### ۱. ایجاد محیط مجازی پایتون

#### لینوکس / macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
```

#### ویندوز (Command Prompt)

```cmd
python -m venv .venv
.venv\Scripts\activate
```

#### ویندوز (PowerShell)

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

### ۲. نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

### ۳. اجرای سرور

```bash
uvicorn src.server.app:app
```

برنامه با استفاده از نمونه `app` تعریف‌شده در `src/server/app.py` اجرا خواهد شد.

### ۴. باز کردن برنامه

مرورگر وب خود را باز کرده و به آدرس زیر مراجعه کنید:

```text
http://127.0.0.1:8000
```

## آزمایش

برای آزمایش دسترسی مبتنی بر نقش، از صفحه ورود با کاربران زیر استفاده کنید:

* `405100`: مدیر سیستم (Admin)
* `405101`: مدیر فناوری اطلاعات
* `405300`: کارشناس فناوری اطلاعات
* `405500`: دانشجو

هر نقش دارای سطح دسترسی و امکانات مخصوص به خود است.

## اهداف پروژه

* ثبت و پیگیری متمرکز تیکت‌ها
* تخصیص تیکت‌ها به واحدهای مسئول و کارشناسان فناوری اطلاعات
* مدیریت درخواست‌های پشتیبانی و ارتباطات
* اعلان‌ها و پیگیری وضعیت
* گزارش‌گیری و پایش فعالیت‌های پشتیبانی

## دامنه پروژه

این پروژه شامل موارد زیر است:

* تحلیل نیازمندی‌ها
* مدل‌سازی موارد کاربرد (Use Case)
* مدل‌سازی دامنه (Domain Modeling)
* طراحی نمودار موجودیت-رابطه (ERD)
* طراحی پایگاه داده
* طراحی معماری سیستم
* طراحی نقش‌ها و مجوزها
* توسعه REST API
* پیاده‌سازی بک‌اند
* پیاده‌سازی فرانت‌اند

## فناوری‌های مورد استفاده

### بک‌اند

* Python
* FastAPI
* SQLAlchemy
* SQLite

### فرانت‌اند

* صفحات ایستای HTML و CSS
