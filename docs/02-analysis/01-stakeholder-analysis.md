# بررسی ذینفعان

ذینفعان (Stakeholders) افرادی هستند که به‌صورت مستقیم یا غیرمستقیم با سامانه Help Desk در ارتباط بوده و از عملکرد آن تأثیر می‌پذیرند. شناسایی ذینفعان و نقش هر یک از آن‌ها در مراحل تحلیل و طراحی سیستم از اهمیت بالایی برخوردار است؛ زیرا نیازمندی‌ها، فرآیندها و سطح دسترسی کاربران بر اساس مسئولیت‌ها و تعاملات آن‌ها با سامانه تعیین می‌شود.

در سامانه Help Desk دانشگاه، ذینفعان اصلی و نقش آن‌ها به شرح زیر است:

<div align="right">

| نقش | ذینفع |
|-----:|-----:|
| ثبت، مشاهده و پیگیری درخواست‌های پشتیبانی | دانشجو |
| ثبت، مشاهده و پیگیری درخواست‌های پشتیبانی | کارمند |
| بررسی، رسیدگی و پاسخ‌گویی به درخواست‌های ارجاع‌شده | کارشناس IT |
| مدیریت فرآیند رسیدگی به تیکت‌ها، تخصیص درخواست‌ها و نظارت بر عملکرد سامانه | مدیر Help Desk (سرپرست تیم پشتیبانی) |
| نظارت بر عملکرد واحد پشتیبانی و تهیه گزارش‌های مدیریتی | مدیر IT |
| مدیریت کاربران، تنظیمات سامانه، سطوح دسترسی و نگهداری فنی سیستم | مدیر سامانه (System Administrator) |

</div>

ذینفعان معرفی‌شده در این بخش، بازیگران اصلی سامانه محسوب می‌شوند و تعاملات آن‌ها با سیستم در مراحل بعدی تحلیل، از جمله استخراج نیازمندی‌ها، تعریف Use Caseها و طراحی فرآیندهای سیستم مورد استفاده قرار خواهد گرفت.
