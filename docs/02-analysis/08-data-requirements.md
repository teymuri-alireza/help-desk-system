# نیازمندی‌های داده‌ای

نیازمندی‌های داده‌ای مشخص می‌کنند که سامانه Help Desk برای انجام وظایف خود به چه اطلاعاتی نیاز دارد و چه داده‌هایی باید در سیستم ذخیره و مدیریت شوند.

هدف این بخش، شناسایی داده‌های اصلی مورد نیاز سامانه و ارتباط آن‌ها با فرآیندهای کسب‌وکار است. اطلاعات ارائه‌شده در این بخش مبنای طراحی مدل داده و پایگاه داده در مراحل بعدی پروژه خواهد بود.

## اطلاعات کاربران (User Data)

- شناسه کاربر
- نام و نام خانوادگی
- نام کاربری
- شناسه کاربری
- پست الکترونیکی
- نقش کاربری
- وضعیت حساب کاربری
- تاریخ ایجاد حساب

## اطلاعات تیکت‌ها (Ticket Data)

- شناسه تیکت
- عنوان درخواست
- شرح مشکل
- وضعیت فعلی
- اولویت
- تاریخ ثبت
- تاریخ آخرین به‌روزرسانی
- شناسه کاربر ثبت‌کننده
- دسته‌بندی تیکت
- واحد مسئول رسیدگی

## اطلاعات پاسخ‌ها (Response Data)

- شناسه پاسخ
- شناسه تیکت
- شناسه ثبت‌کننده پاسخ
- متن پاسخ
- تاریخ ثبت پاسخ

## اطلاعات دسته‌بندی‌ها (Category Data)

- شناسه دسته‌بندی
- نام دسته‌بندی

## اطلاعات واحدهای سازمانی (Department Data)

- شناسه واحد
- نام واحد

## اطلاعات فایل‌های پیوست (Attachment Data)

- شناسه فایل
- نام فایل
- نوع فایل
- شناسه کاربر بارگذاری کننده
- مسیر ذخیره‌سازی
- تاریخ بارگذاری

## اطلاعات اعلان‌ها (Notification Data)

- شناسه اعلان
- گیرنده اعلان
- عنوان اعلان
- متن اعلان
- وضعیت مشاهده
- تاریخ ایجاد
