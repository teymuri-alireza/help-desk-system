# نیازمندی‌های عملکردی سیستم

نیازمندی‌های عملکردی قابلیت‌ها و خدماتی را مشخص می‌کنند که سامانه Help Desk باید در اختیار کاربران قرار دهد. این نیازمندی‌ها مبنای طراحی فرآیندها، Use Caseها و اجزای مختلف سیستم خواهند بود.

## نیاز اول ‍`(FR-01)` : ثبت تیکت جدید

سامانه باید امکان ثبت درخواست پشتیبانی جدید را برای کاربران مجاز فراهم کند. هر تیکت باید شامل اطلاعاتی نظیر عنوان، شرح مشکل، زمان ثبت، وضعیت فعلی و اطلاعات کاربر ثبت‌کننده باشد.

## نیاز دوم `(FR-02)` : مشاهده و پیگیری وضعیت تیکت

سامانه باید امکان مشاهده وضعیت تیکت‌های ثبت‌شده را برای کاربران فراهم کند. کاربران باید بتوانند آخرین وضعیت درخواست خود و سوابق مرتبط با آن را مشاهده و پیگیری کنند.

## نیاز سوم `(FR-03)` : تخصیص تیکت به کارشناس مربوطه

سامانه باید امکان ارجاع و تخصیص تیکت‌ها به کارشناسان یا واحدهای مرتبط را فراهم کند. این قابلیت باید به مدیر Help Desk اجازه دهد تا درخواست‌ها را بر اساس نوع مشکل یا حوزه تخصصی به کارشناس مناسب ارجاع دهند.

## نیاز چهارم `(FR-04)` : ثبت پاسخ و به‌روزرسانی تیکت

سامانه باید به کارشناسان پشتیبانی اجازه دهد پاسخ‌ها و اقدامات انجام‌شده را برای هر تیکت ثبت کنند. همچنین امکان به‌روزرسانی وضعیت تیکت در مراحل مختلف رسیدگی باید فراهم باشد.

## نیاز پنجم `(FR-05)` : مدیریت وضعیت تیکت‌ها

سامانه باید امکان مدیریت وضعیت تیکت‌ها را فراهم کند. هر تیکت می‌تواند در وضعیت‌هایی نظیر «جدید»، «در حال بررسی»، «ارجاع‌شده»، «حل‌شده» یا «بسته‌شده» قرار گیرد و کاربران مجاز بتوانند وضعیت آن را تغییر دهند.

## نیاز ششم `(FR-06)` : مشاهده تاریخچه تیکت‌ها

سامانه باید سوابق تمامی فعالیت‌های انجام‌شده روی هر تیکت را نگهداری کرده و امکان مشاهده تاریخچه تغییرات، پاسخ‌ها و وضعیت‌های قبلی را فراهم کند.

## نیاز هفتم `(FR-07)` : گزارش‌گیری مدیریتی

سامانه باید امکان تهیه گزارش‌های مدیریتی از درخواست‌های پشتیبانی را فراهم کند. مدیران باید بتوانند اطلاعاتی نظیر تعداد تیکت‌ها، وضعیت درخواست‌ها، حجم فعالیت کارشناسان و روند رسیدگی به مشکلات را مشاهده و بررسی کنند.
