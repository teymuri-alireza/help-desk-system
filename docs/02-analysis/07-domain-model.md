# مدل دامنه (Domain Model)

مدل دامنه نمایی مفهومی از موجودیت‌ها و مفاهیم اصلی سامانه Help Desk ارائه می‌کند. هدف از این مدل، شناسایی عناصر کلیدی دامنه مسئله و روابط میان آن‌ها پیش از ورود به مراحل طراحی پایگاه داده و پیاده‌سازی است.

در این مرحله، تمرکز بر درک ساختار منطقی سامانه و نحوه تعامل اجزای اصلی آن بوده و جزئیات فنی مورد بررسی قرار نمی‌گیرند.

## مفاهیم اصلی دامنه

- ### User

نمایانگر تمامی کاربران سامانه است. کاربران می‌توانند دارای نقش‌های مختلفی از جمله دانشجو، کارمند، کارشناس فناوری اطلاعات، مدیر Help Desk، مدیر فناوری اطلاعات و مدیر سامانه باشند.

- ### Ticket

نمایانگر یک درخواست پشتیبانی ثبت‌شده توسط کاربر است. هر تیکت شامل اطلاعات مربوط به مشکل، وضعیت فعلی، زمان ثبت و سایر اطلاعات مرتبط با فرآیند رسیدگی خواهد بود.

- ### Response

نمایانگر پاسخ‌ها یا اقدامات ثبت‌شده در ارتباط با یک تیکت است. کارشناسان و کاربران مجاز می‌توانند در طول چرخه رسیدگی به تیکت پاسخ‌هایی را ثبت کنند.

- ### Category

برای دسته‌بندی درخواست‌های پشتیبانی مورد استفاده قرار می‌گیرد. هر تیکت می‌تواند در یک دسته مشخص قرار گیرد تا فرآیند ارجاع و رسیدگی به آن تسهیل شود.

- ### Department

نمایانگر واحد یا بخش مسئول رسیدگی به درخواست‌های پشتیبانی است. کارشناسان می‌توانند به یک یا چند بخش سازمانی وابسته باشند.

- ### Attachment

نمایانگر فایل‌های ضمیمه‌شده به تیکت‌ها یا پاسخ‌ها است. کاربران می‌توانند مستندات، تصاویر یا سایر فایل‌های مرتبط با مشکل خود را به سامانه ارسال کنند.

- ### Notification

نمایانگر اعلان‌های تولیدشده توسط سامانه است. این اعلان‌ها برای اطلاع‌رسانی تغییر وضعیت تیکت‌ها، ثبت پاسخ جدید یا سایر رویدادهای مهم مورد استفاده قرار می‌گیرند.

## روابط مفهومی

روابط اصلی میان مفاهیم دامنه به شرح زیر است:

* هر User می‌تواند چندین Ticket ثبت کند.
* هر Ticket توسط یک User ایجاد می‌شود.
* هر Ticket می‌تواند شامل چندین Response باشد.
* هر Response به یک Ticket تعلق دارد.
* هر Response توسط یک User ثبت می‌شود.
* هر Ticket در یک Category قرار می‌گیرد.
* هر Ticket می‌تواند به یک Department ارجاع داده شود.
* هر Ticket می‌تواند دارای چندین Attachment باشد.
* هر Response می‌تواند دارای چندین Attachment باشد.
* هر User می‌تواند چندین Notification دریافت کند.
* هر Notification به یک User مرتبط است.

## نمودار مدل دامنه

به‌منظور نمایش تصویری مفاهیم و روابط معرفی‌شده در این بخش، نمودار Domain Model Diagram در پوشه نمودارهای پروژه ارائه شده است. این نمودار مبنای طراحی مدل داده و ساختار پایگاه داده در مراحل بعدی پروژه خواهد بود.
