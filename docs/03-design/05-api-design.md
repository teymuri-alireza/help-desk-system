# طراحی رابط برنامه‌نویسی کاربردی (API Design)

تمامی Endpointهای معرفی‌شده در این سند به‌صورت RESTful طراحی شده‌اند و جزئیات پیاده‌سازی آن‌ها در مراحل توسعه مشخص خواهد شد.

## احراز هویت و مدیریت نشست

### ثبت‌نام کاربر

```
POST /auth/signup‍‍
```

ایجاد حساب کاربری جدید در سامانه.

### ورود به سامانه

```
POST /auth/login
```

احراز هویت کاربر و ایجاد نشست یا توکن دسترسی.

### دریافت اطلاعات کاربر جاری

```
GET /auth/me
```

دریافت اطلاعات کاربر احراز هویت‌شده.

## داشبورد

### دریافت اطلاعات داشبورد

```
GET /dashboard
```

دریافت اطلاعات مورد نیاز داشبورد متناسب با نقش کاربر.

## مدیریت تیکت‌ها

### مشاهده فهرست تیکت‌ها

```
GET /tickets
```

نمایش فهرست تیکت‌های قابل مشاهده برای کاربر.

### مشاهده جزئیات تیکت

```
GET /tickets/{ticket_id}
```

نمایش اطلاعات کامل یک تیکت مشخص.

### ثبت تیکت جدید

```
POST /tickets
```

ایجاد درخواست پشتیبانی جدید.

### تخصیص تیکت

```
POST /tickets/{ticket_id}/assign
```

اختصاص یک تیکت به کارشناس یا واحد مسئول رسیدگی.

### ویرایش اطلاعات تیکت

```
PATCH /tickets/{ticket_id}
```

به‌روزرسانی بخشی از اطلاعات تیکت نظیر وضعیت، اولویت یا واحد مسئول.

## مدیریت پاسخ‌ها

### مشاهده پاسخ‌های تیکت

```
GET /tickets/{ticket_id}/responses
```

دریافت فهرست پاسخ‌های مرتبط با یک تیکت.

### ثبت پاسخ جدید

```
POST /tickets/{ticket_id}/responses
```

ثبت پاسخ جدید برای تیکت مورد نظر.

این Endpoint از ساختار پاسخ‌های تو در تو (Threaded Responses) پشتیبانی می‌کند.

## اعلان‌ها

### مشاهده اعلان‌ها

```
GET /notifications
```

دریافت فهرست اعلان‌های مربوط به کاربر جاری.

## مدیریت کاربران

### مشاهده فهرست کاربران

```
GET /users
```

نمایش فهرست کاربران سامانه.

دسترسی به این Endpoint محدود به نقش‌های مدیریتی است.

### مشاهده اطلاعات کاربر

```
GET /users/{user_id}
```

نمایش اطلاعات یک کاربر مشخص.

### ایجاد کاربر جدید

```
POST /users
```

ایجاد حساب کاربری جدید توسط مدیر سامانه.

### ویرایش اطلاعات کاربر

```
PATCH /users/{user_id}
```

به‌روزرسانی اطلاعات یا نقش یک کاربر.
